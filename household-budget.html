Household Budget Tracker 가계부

A bilingual Excel workbook for tracking monthly household expenses — with rolling balances, category breakdowns, and per-month pie charts. 롤링 잔액, 카테고리별 분류, 월별 파이 차트를 포함한 한국어/영어 이중 언어 가계부 엑셀 파일입니다.

Free to download and use. Open in Microsoft Excel for full formula support. 무료로 다운로드하여 사용하세요. 수식 전체 지원은 Microsoft Excel에서 여세요.

가계부 (한국어) Budget (English)

What Is This? 이 파일은 무엇인가요?

A personal finance tool I built in Excel to track household spending month by month. 월별 가계 지출을 기록하기 위해 엑셀로 직접 만든 개인 재무 관리 도구입니다.

Most budgeting apps are either too complex or lock your data behind a subscription. I wanted something I fully own and understand — so I built it myself in Excel. The workbook is structured around a central monthly ledger, a rolling balance that carries forward automatically, and auto-generated pie charts so you can see exactly where your money is going each month. Both a Korean (가계부) and English version are available. 대부분의 가계부 앱은 너무 복잡하거나 구독 서비스 뒤에 데이터를 가둬놓습니다. 내가 완전히 소유하고 이해할 수 있는 도구를 원해서 직접 엑셀로 만들었습니다. 이 통합 문서는 중앙 월별 장부, 자동으로 이월되는 롤링 잔액, 그리고 매달 어디에 돈이 쓰이는지 바로 알 수 있는 자동 생성 파이 차트로 구성되어 있습니다. 한국어 버전(가계부)과 영어 버전 모두 제공됩니다.

Key Features 주요 기능

Everything you need, nothing you don't. 필요한 것만, 군더더기 없이.

Rolling Balance롤링 잔액

Cell H31 carries the closing balance forward into the next month automatically — no manual copying needed. H31 셀이 마감 잔액을 다음 달로 자동 이월합니다. 수동으로 복사할 필요가 없습니다.

Per-Month Pie Charts월별 파이 차트

Each monthly sheet includes a pie chart auto-built from hidden helper tables — shows your spending breakdown at a glance. 각 월별 시트에는 숨겨진 보조 테이블로 자동 생성된 파이 차트가 포함되어 있어 지출 내역을 한눈에 확인할 수 있습니다.

10 Expense Categories10가지 지출 항목

Housing, food, transportation, health, subscriptions, and more — each line item is tagged for automatic SUMIF aggregation. 주거, 식비, 교통, 건강, 구독료 등 — 각 항목은 SUMIF 자동 집계를 위해 카테고리 태그가 붙어 있습니다.

SUMIF TotalsSUMIF 자동 합계

Category totals are calculated automatically using SUMIF — add any number of rows without touching the formulas. 카테고리 합계는 SUMIF로 자동 계산됩니다. 수식을 건드리지 않고 행을 자유롭게 추가할 수 있습니다.

Bilingual (KR / EN)이중 언어 (한/영)

Two identical versions — one fully in Korean, one in English. Same formula logic, same structure. 한국어 버전과 영어 버전 두 가지를 제공합니다. 동일한 수식과 구조입니다.

Clean & Minimal깔끔하고 단순한 구조

No macros, no VBA, no plugins required. Pure Excel formulas — works on any device that opens .xlsx files. 매크로, VBA, 플러그인 불필요. 순수 엑셀 수식만 사용 — .xlsx 파일을 열 수 있는 모든 기기에서 작동합니다.

Workbook Structure 통합 문서 구조

Each month gets its own sheet. The layout is identical across all months. 각 달은 자체 시트를 가집니다. 모든 달의 레이아웃은 동일합니다.

Monthly Sheet (×12)월별 시트 (×12)

One sheet per month. Rows for each expense, columns for date / description / category / amount.월마다 시트 하나. 날짜 / 내용 / 카테고리 / 금액 열로 구성된 지출 행.

Category Totals (H31 area)카테고리 합계 (H31 영역)

SUMIF totals per category, closing balance, and opening balance feed for the next sheet.카테고리별 SUMIF 합계, 마감 잔액, 다음 시트로의 시작 잔액 전달.

Hidden Helper Table숨겨진 보조 테이블

Expense Categories 지출 카테고리

Each transaction is tagged with one of 10 categories. The SUMIF formula totals them automatically — just type the category name in column C and the math handles itself. 각 거래는 10가지 카테고리 중 하나로 태그됩니다. SUMIF 수식이 자동으로 합산합니다 — C열에 카테고리 이름만 입력하면 계산이 자동으로 됩니다.

The Rolling Balance Formula 롤링 잔액 수식

The core of the workbook. Cell H31 on each monthly sheet holds the closing balance, which is automatically pulled into H2 (opening balance) of the next month's sheet. No copy-pasting required — just keep logging expenses and the balance flows forward. 통합 문서의 핵심입니다. 각 월별 시트의 H31 셀에 마감 잔액이 저장되며, 이 값이 다음 달 시트의 H2(시작 잔액)로 자동으로 전달됩니다. 복사-붙여넣기가 필요 없습니다 — 지출만 계속 기록하면 잔액이 자동으로 이월됩니다.

# Next month's opening balance (e.g. in February's H2)# 다음 달 시작 잔액 (예: 2월 H2) =January1월!H31 # Closing balance on each sheet# 각 시트의 마감 잔액 =H2 - SUMIF(C5:C30,"<>",E5:E30) # Category total (e.g. Food)# 카테고리 합계 (예: 식비) =SUMIF(C5:C30,"Food",E5:E30C5:C30,"식비",E5:E30)

How to Use It 사용 방법

Five steps and you're up and running. 다섯 단계만 따라하면 바로 시작할 수 있습니다.

  • 1

    Download the file파일 다운로드

    Choose the Korean (가계부) or English version above. Open in Microsoft Excel — Google Sheets works but chart rendering may vary.위에서 한국어(가계부) 또는 영어 버전을 선택하세요. Microsoft Excel에서 여세요 — Google Sheets도 가능하지만 차트 렌더링이 다를 수 있습니다.

  • 2

    Set your opening balance시작 잔액 입력

    On the first month's sheet, enter your starting balance in cell H2. This is the amount you're beginning to track from.첫 달 시트의 H2 셀에 시작 잔액을 입력하세요. 추적을 시작할 금액입니다.

  • 3

    Log each expense지출 기록

    Fill in columns A–E: date, description, category (from the 10 options), income flag, and amount. The balance column updates automatically.A~E 열을 채우세요: 날짜, 내용, 카테고리(10가지 중 선택), 수입 여부, 금액. 잔액 열은 자동으로 업데이트됩니다.

  • 4

    Check your pie chart파이 차트 확인

    The pie chart on each sheet auto-refreshes as you log expenses. It reads from a hidden helper table (rows 35+) — don't delete those rows.각 시트의 파이 차트는 지출을 기록할 때마다 자동으로 갱신됩니다. 숨겨진 보조 테이블(35행 이후)에서 데이터를 읽으므로 해당 행을 삭제하지 마세요.

  • 5

    Move to the next month다음 달로 넘어가기

    H31 (closing balance) flows into the next sheet's H2 automatically via a sheet reference. Just switch tabs and start logging.H31(마감 잔액)은 시트 참조를 통해 다음 시트의 H2로 자동 전달됩니다. 탭을 이동하고 바로 기록을 시작하면 됩니다.
