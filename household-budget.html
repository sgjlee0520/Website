How the System Works 시스템 구조

Excel / openpyxl

Built with PythonPython으로 제작

The workbook is programmatically generated using openpyxl — formulas, formatting, and per-month pie charts are all written in code, not manually. 통합 문서는 openpyxl을 사용해 프로그래밍 방식으로 생성됩니다. 수식, 서식, 월별 파이 차트 모두 코드로 작성되었습니다.

Rolling Balance

Cumulative Tracking누적 잔액 추적

Each month's remaining balance automatically carries forward to the next sheet using a dynamic cross-sheet formula — no manual entry required. 각 월의 남은 잔액은 동적 교차 시트 수식을 사용해 다음 시트로 자동으로 이월됩니다.

SUMIF

Category Totals항목별 합계

Per-category totals are driven by SUMIF formulas across 200 transaction rows — add an entry with a category tag and the totals update instantly. 항목별 합계는 200개의 거래 행에 걸친 SUMIF 수식으로 계산됩니다. 항목 태그로 항목을 추가하면 합계가 즉시 업데이트됩니다.

Pie Charts

Visual Breakdown시각적 분석

Each month sheet includes an auto-generated pie chart showing only the categories with actual spending — zero-value categories are excluded automatically. 각 월별 시트에는 실제 지출이 있는 항목만 표시하는 자동 생성 파이 차트가 포함됩니다.

Bilingual

KR / EN Versions한국어 / 영어 버전

Two separate workbooks — one in Korean (가계부_한국어.xlsx) and one in English — with identical structure but localized labels and category names. 한국어와 영어 두 가지 별도 통합 문서로, 동일한 구조이지만 현지화된 레이블과 항목명을 사용합니다.

New Month Template

One-Click Expansion원클릭 확장

A pre-built template sheet is included so adding a new month takes seconds — copy, rename, and the formulas self-configure for the new period. 미리 만들어진 템플릿 시트가 포함되어 있어 새 달 추가가 몇 초면 됩니다. 복사하고 이름을 바꾸면 수식이 새 기간에 맞게 자동 구성됩니다.
