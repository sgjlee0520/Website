Project Overview프로젝트 개요

scrooge runs OCR and plot-to-data conversion on your own machine, so an AI agent works from compact text and numbers instead of raw images. PDFs become text through Tesseract OCR, and plots become digitized curve data. This uses up to about 35 times fewer tokens than sending the images to a vision model. scrooge는 OCR과 플롯 데이터 변환을 내 컴퓨터에서 실행해, AI 에이전트가 원본 이미지 대신 짧은 텍스트와 숫자로 작업하게 합니다. PDF는 Tesseract OCR로 텍스트가 되고, 그래프는 디지털화된 곡선 데이터가 됩니다. 이미지를 비전 모델에 그대로 넣을 때보다 토큰을 최대 약 35배 적게 씁니다.

I built it as a utility for lab work. It digitizes plots from papers and lab notebooks, extracts tables from scanned handouts, and serves both through an MCP server so that coding agents can call them as tools. A demo runs on Hugging Face Spaces, and the full pipeline runs locally. 실험실 작업에 쓰려고 만든 도구입니다. 논문과 실험 노트의 그래프를 디지털화하고, 스캔한 자료에서 표를 추출하며, MCP 서버를 통해 코딩 에이전트가 이 기능을 도구로 호출할 수 있습니다. 데모는 Hugging Face Spaces에서 실행되고, 전체 파이프라인은 로컬에서 실행됩니다.
