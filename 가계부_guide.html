핵심 수식 예시

// 카테고리별 합계 (SUMIF) =SUMIF(D$2:D$202, "외식", B$2:B$202) // 기타 자동 계산: 총합 − 9개 카테고리 H5 - SUM(H6:H14) // 전월 비교 %, INDIRECT로 어느 달에서든 작동 =IFERROR((H5 - INDIRECT("'"&$H$2&"'!H5")) / INDIRECT("'"&$H$2&"'!H5"), "") // 월 누적 합계 (running total) =E3 + IFERROR(B4, 0) // 잔고 소진 예상일 =TODAY() + (H31 / H32) * 30

💡 $H$2에 이전 달 시트명을 입력하면 전월 비교 수식이 전부 자동으로 작동합니다. 새 달 시트를 복사할 때 이 셀 하나만 바꾸면 됩니다.

사용법

새 달 시작하기

3단계로 새 달 준비 완료, 수식 재작성 없음.

1

기존 월 탭 복사

워크북에서 예를 들어 "Feb 2026" 탭을 우클릭 → Move or Copy → Create a copy 체크 → OK.

2

탭 이름 변경 및 노란 셀 3개 업데이트

새 탭 이름을 Mar 2026로 변경. 그 다음 노란 셀만 업데이트:

  • H2, 이전 달 시트명: Feb 2026
  • H23, 계산 기준 일수: 31
  • H31, 현재 은행 잔고
3

기존 거래 내역 삭제 후 새 달 입력 시작

A-D 열의 이전 달 데이터를 선택 후 삭제. E열(월 누적)은 수식이라 건드리지 않아도 됩니다. 새 거래를 입력하면 오른쪽 통계 패널이 즉시 업데이트됩니다.

셀 색상 규칙

노란색 = 직접 입력
하늘색 = 합계 행
회색 = 수식 자동 계산
파란 글씨 = 직접 입력 값

팁

지출을 줄이기 위한 인사이트

이 시스템을 쓰면서 배운 것들.

📉

외식:요리 비율 ≤ 1 목표

외식이 식재료보다 적으면 비율 ≤1. 이 지표 하나로 식비 습관을 즉시 진단합니다.

🛍️

사치 음식 분리 추적

Monster, 도넛, 초콜릿을 "보조제"나 "외식"으로 묶으면 눈에 안 보입니다. 따로 분리하면 한 달 총액에 깜짝 놀라게 됩니다.

🎯

1일당 식비 목표 설정

일 $15 목표를 설정하면 "오늘 외식 $25, 이번 주 예산 초과"를 즉시 감지할 수 있습니다.

✈️

여행비 별도 분리

여행 카테고리를 분리하면 여행 없는 달의 순수 생활비를 정확히 파악할 수 있습니다.
