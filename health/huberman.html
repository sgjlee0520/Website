Core operating principles

Circadian anchor

Morning sunlight + stable wake time

Use outdoor light shortly after waking to lock circadian timing and improve evening sleep pressure.

Focus architecture

90-minute deep work cycles

Run intense cognitive blocks in ultradian windows with deliberate defocus breaks in between.

Neuroplasticity

Active recall + difficulty

Prioritize retrieval and error-driven learning over passive reading for stronger memory retention.

Recovery as output

NSDR + sleep protection

Consolidation happens during rest. Treat recovery as part of the protocol, not optional overhead.
